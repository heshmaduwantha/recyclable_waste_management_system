# EcoCollect Frontend Rules

- Use React Native with TypeScript.
- Use functional components only.
- Use React Navigation.
- Use feature-based folder structure.
- Use reusable UI components.
- Use Context API for authentication.
- Keep API calls inside services.
- Do not place business logic inside UI components.
- Use mock data until backend integration.
- Customer theme = Blue.
- Picker theme = Green.
- Admin theme = Graphite.
- Reuse components whenever possible.
- Follow atomic and scalable architecture.
